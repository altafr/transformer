Eleven ideas

Each card has the same beats: what it is, a small worked example, and an everyday automation comparison.

1Vector

A vector is a list of numbers that describes one thing. The order is fixed: position 1 always means the same thing, so two vectors can be compared position by position.

ticket = [urgency 7, order value 3, age 5]
Think of it asA spreadsheet row where every column is a number.

2Multidimensional space

Every number in a vector is a coordinate along its own axis. One number places a point on a line, two on a flat plane, three in a room. A vector with n numbers places a point in n-dimensional space. You can only draw two or three axes, but positions, distances and angles follow the same rules with 10 axes or 1,000.

Why use so many axes? Each extra axis is one more way for two things to differ. Two cases can look identical on two measures and still be far apart on a third, so more axes allow finer distinctions.

[3, 4] and [3, 4] are the same point
[3, 4, 0] and [3, 4, 9] are 9 apart once a third axis is added
Think of it asA spreadsheet with n numeric columns: every row is a point, and every column is an axis.

3Closeness: distance and angle

To compare two points, measure the distance between them: in any number of dimensions, subtract position by position, square each difference, add them up and take the square root. Or compare the angle between the arrows from the origin: do they point the same way?

[2, 5, 1] to [2, 6, 3]: differences [0, 1, 2] → √(0 + 1 + 4) ≈ 2.2
[2, 5, 1] to [9, 1, 8]: differences [7, −4, 7] → √114 ≈ 10.7
[1, 1] and [2, 2] point the same way; [1, 0] and [0, 1] are at right angles
Think of it asPlot every past case as a point. A new case that lands near a cluster probably behaves like that cluster.

4Dot product

Multiply two vectors position by position, then add up. You get one number that says how well they match. Big and positive means they point the same way, near zero means unrelated, negative means opposite.

[2, 1, 0] · [1, 3, 5] = 2×1 + 1×3 + 0×5 = 5
Think of it asA lead score: each fact about a lead is multiplied by how much it matters, then added up.

5Matrix multiplication

A matrix is a table of numbers. Multiplying a vector by a matrix takes the dot product with each column and gives a new vector, possibly of a different length. The shapes must line up: (1 × 3) times (3 × 2) gives (1 × 2).

[1, 2, 3] × [[1, 0], [0, 1], [1, 1]] = [1+0+3, 0+2+3] = [4, 5]
Think of it asOne mapping table applied to a whole row at once. Each output column is a scoring rule, and the matrix holds all the rules together.

6Softmax

Softmax turns any list of scores into percentages that add up to 100%. The highest score gets the biggest share, and nobody gets exactly 0% or 100%. Dividing the scores by a number above 1 first flattens the shares, and below 1 sharpens them.

scores [2, 1, 0] → 67% | 24% | 9%
Think of it asSeveral classifiers each give a confidence. Softmax turns them into one set of shares you can route on.

7Probability and weighted choice

If the shares are 50%, 30% and 20%, a weighted choice is a raffle where each option holds that share of the tickets. Any single draw can come out differently, but over many draws the counts settle near the shares. Always taking the largest share instead gives the same answer every time.

50 / 30 / 20 → over 100 draws, expect about 50, 30 and 20 (not exactly)
Think of it asA router that either always takes the top route, or sends traffic in proportion to confidence. The first is repeatable, the second adds variety.

8Straight lines and bends

Multiplying and adding only ever produce straight-line behaviour, and a chain of straight steps is still one straight step. A small bend, such as “output the input, but never below zero” (written max(0, x)), breaks that, so a chain of steps can follow curves.

double, add 3, triple = 3 × (2x + 3) = 6x + 9: still a straight line
max(0, −2) = 0 and max(0, 3) = 3: a bend
Think of it asAn IF rule: do nothing below a threshold, act above it. Without a step like that, ten calculations collapse into one.

9Rescaling

To keep numbers in a comfortable range, subtract their average and divide by their spread (standard deviation). The result always has average 0 and spread 1, whatever the starting scale.

[3, 9, 6]: average 6, spread 2.45 → [−1.22, 1.22, 0]
Think of it asPutting every sensor on the same scale before comparing them.

10Error and nudging

To find good settings without knowing the answer in advance, guess, measure the error, nudge, repeat. Each nudge moves a setting a little in the direction that shrinks the error. This is the idea behind finding the best settings by trial and refinement.

prediction = w × 2, target 6. w = 2 → 4 (error 2). w = 2.5 → 5 (error 1). w = 3 → 6 (error 0)
Think of it asTuning a rule threshold against past cases: run, check how many it gets wrong, adjust, run again.

11Feedback loops

Take an output and feed it back in as the next input. Each pass uses everything that came before, so small rules can build long results, and the number of passes decides the length of the result.

start at 1, double and add 1: 1 → 3 → 7 → 15 → 31
Think of it asA workflow that calls itself, or interest that earns interest.

Words you will see

Dimension
How many numbers a vector has.
Weight
A number that says how much something counts. A table of weights is a matrix.
Score
One number that rates how good, large or relevant something is.
Probability
A share between 0% and 100%. All the options together add up to 100%.
Function
A rule that turns an input number into an output number.
Iteration
Doing the same step again and again, each time starting from the last result.
Every example uses small, made-up numbers so you can check them by hand.
